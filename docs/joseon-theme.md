# 조선시대 테마: 점순 살인 사건

> 문서 상태: **현재 로컬 구현 기준 정리본**
> 최종 갱신: 2026-09-02
> 기준: 사용자 확정 사항 → 실제 구현 → 기존 기획 문서

## 1. 테마 요약

조선의 양반가 앞에서 몸종 점순이 목 졸려 숨진 채 발견된다. 현장에 남은 유문석의 호패와 돌쇠가 보낸 듯한 편지는 두 남자를 범인처럼 보이게 하지만, 실제로는 돌쇠에게 집착한 춘월이 도망 계획을 알아낸 뒤 점순을 유인해 살해하고 타인의 흔적으로 누명을 꾸민 사건이다.

## 2. 플레이어 역할과 핵심 루프

- 역할: `사또`
- 목표: 점순의 마지막 동선, 조작된 호패, 가짜 약속 편지, 살해 도구와 저항 흔적을 연결해 춘월의 범행을 입증한다.
- 진행: `현장 수색 → 증거 습득 → 보따리 감식·대조 → 심문 → 도구·열쇠 획득 → 잠긴 공간 수색 → 범인 지목`
- 제한시간과 강제 실패는 없다. 막혔을 때는 아직 찾지 않은 증거와 심문으로 진행할 수 있어야 한다.

## 3. 핵심 정서

- 신분과 체면, 선택할 수 없는 삶, 사랑이 집착과 통제로 뒤틀리는 과정이 중심이다.
- 점순과 돌쇠의 도망은 억압된 삶에서 벗어나려는 선택이다.
- 춘월의 원치 않는 혼인은 동기를 설명하지만 범행을 정당화하지 않는다.
- 유문석·돌쇠·무덕이 숨기는 사실과 살인 혐의는 구분한다.

## 4. 등장인물

| 인물 | 역할 | 숨기는 사실 | 수사상 기능 |
|---|---|---|---|
| 점순 | 피해자, 몸종 | 돌쇠와 떠날 계획 | 편지에 속아 창고로 향하고 범인의 팔을 긁음 |
| 춘월 | 유문석의 정혼자, 범인 | 돌쇠에 대한 집착, 사랑방 출입, 범행 흔적 | 그림·혼서·저고리·팔 상처·호패 조작이 연결됨 |
| 돌쇠 | 머슴, 점순의 연인 | 밤 만남과 도망 계획 | 초기 용의자이나 말투·붕대·상처 대조로 혐의가 약해짐 |
| 유문석 | 양반가 도련님 | 점순을 꾸짖은 일과 호패 분실 | 호패로 의심받지만 조작된 누명임이 드러남 |
| 무덕 | 어린 하인, 간접 목격자 | 밤 기척과 춘월에게 정보를 전한 일 | 일기로 시간선을 잇고 심문 후 열쇠를 건넴 |

## 5. 실제 사건

1. 점순과 돌쇠는 함께 떠나기로 약속하고 도망 보따리를 준비한다.
2. 무덕은 두 사람의 밤 만남을 눈치채고 춘월에게 점순의 외출과 돌쇠 이야기를 흘린다.
3. 돌쇠에게 집착하던 춘월은 두 사람의 도망 계획을 알고 점순을 없애기로 한다.
4. 춘월은 돌쇠인 척 정중한 약속 편지를 써 점순을 창고로 불러낸다.
5. 춘월은 자신의 저고리 옷고름으로 점순의 목을 조른다.
6. 점순은 저항하며 춘월의 팔을 여러 갈래로 긁는다.
7. 춘월은 사랑방에서 가져온 유문석의 호패를 훼손해 현장에 놓는다.
8. 범행에 사용한 찢어진 옷고름은 뒷문 마당 장독 안에 숨긴다.

## 6. 실제 시간선 → 첫인상 → 반전

| 시점 | 실제 시간선 | 플레이어가 처음 믿는 내용 | 반전 후 해석 |
|---|---|---|---|
| 6월 29일 | 유문석이 점순을 크게 꾸짖음 | 유문석에게 살해 동기가 있음 | 꾸짖은 사실은 맞지만 살인의 물증은 아님 |
| 6월 30일 밤 | 점순과 돌쇠가 뒷문에서 도망 약속을 확인함 | 돌쇠가 점순을 불러 범행했을 수 있음 | 둘의 만남은 도망 준비였음 |
| 7월 1일 아침 | 무덕이 춘월에게 점순과 돌쇠 이야기를 전함 | 무덕은 단순 목격자임 | 무덕의 말이 춘월에게 계획을 알려 준 경로였음 |
| 초경 무렵 | 춘월이 혼서 문갑을 핑계로 사랑방에 들어감 | 혼례 준비를 위한 출입 | 호패를 가져갈 기회였음 |
| 초경 뒤 | 춘월이 돌쇠를 흉내 낸 편지를 작성함 | 돌쇠가 점순을 다시 불러냄 | 정중한 문장이 돌쇠의 평소 말투와 다름 |
| 이경 | 점순이 편지를 믿고 창고로 향함 | 돌쇠와 만나러 감 | 편지를 쓴 춘월에게 유인됨 |
| 이경 | 춘월이 옷고름으로 점순의 목을 조름 | 유문석 또는 돌쇠와 다투다 죽음 | 목 자국·옷고름·저고리·팔 긁힘이 춘월을 가리킴 |
| 범행 직후 | 춘월이 훼손한 호패를 현장에 둠 | 호패 주인 유문석이 현장에 있었음 | 호패는 누명을 위한 배치 증거임 |
| 범행 직후 | 옷고름을 뒷문 장독에 숨김 | 장독은 평범한 배경임 | 도끼로 깨야 나오는 은닉 증거임 |

## 7. 조사 장소와 현재 배치

| 장소 | 접근 | 증거·도구 | 공간 상호작용 |
|---|---|---|---|
| 유문석 집 앞 | 시작 현장 | `찢어진 약속 편지`, `호패 조각` | 시신 주변과 창고 문간 조사 |
| 춘월의 방 | 수색 전령 | `돌쇠의 그림`, `고름이 뜯긴 저고리`, `작은 쇠열쇠` | 천 젖히기, 잠긴 검은 문갑, 거짓 바닥, 잠긴 의복장 |
| 무덕의 하인방 | 바로 접근 | `무덕의 번진 일기`, `진흙 묻은 짚신` | 일기 펼치기, 짚신 밑창 확인 |
| 유문석 사랑방 | 수색 전령 | `놋쇠 고리열쇠`, `빈 호패 주머니`, `하인 장부`, `혼서 조각` | 붓통, 잠긴 서랍·문갑, 문서 더미 |
| 돌쇠의 처소 | 바로 접근 | `피 묻은 붕대`, `도망 보따리`, `장작 도끼` | 침상·보따리·도구 자리 수색 |
| 뒷문 마당 | 수색 전령 | `작은 발자국`, `끊어진 호패끈`, `찢어진 옷고름` | 금이 간 장독을 도끼로 깨기 |
| 취조실 | 용의자 선택 | `돌쇠의 팔 상처`, `긁힌 팔 흔적`, `매화무늬 장열쇠` | 증거 제시, 추궁, 조건부 열쇠 획득 |

## 8. 수색 전령

수색 전령은 인벤토리 물건인 압수수색패가 아니다. 지도의 제한 장소를 선택했을 때 펼쳐지는 전체 화면 두루마리이며, 필요한 근거가 모이면 플레이어가 관인을 찍어 수색을 허가하는 절차다.

| 대상 | 필요한 근거 | 해금 조건 |
|---|---|---|
| 뒷문 마당 | `찢어진 약속 편지` | 편지를 확보하면 관인을 찍을 수 있음 |
| 유문석 사랑방 | `호패 조각` | 호패를 확보하면 관인을 찍을 수 있음 |
| 춘월의 방 | `찢어진 약속 편지` + `무덕의 번진 일기` | 둘을 확보하고 편지를 보따리에서 읽어야 함 |

### 전령 UI 규칙

- 제목, 짧은 안내, 필요한 증거, 관인 자리만 둔다.
- 증거가 하나면 중앙, 둘이면 나란히 표시한다.
- 도장은 인장 자리 바로 위에서 시작해 클릭 시 이동하고 선명한 인영을 남긴다.
- 닫기는 우측 상단 `X`만 사용한다.
- 지도에서 미해금 장소에는 자물쇠를 표시한다.
- 돌쇠 처소와 무덕 하인방에는 전령을 요구하지 않는다.

## 9. 도구와 열쇠 진행

도구와 열쇠는 실제 획득 뒤에만 보따리에 나타난다. 선택하면 커서가 해당 도구 모양으로 바뀐다.

- 첫 도구가 보따리에 들어온 순간에만 사용 안내를 한 번 표시한다.
- 도구 커서가 활성화된 동안 마우스 오른쪽 버튼을 누르면 선택을 해제하고 기본 커서로 돌아간다.

| 도구 | 획득 | 사용처 | 동작 |
|---|---|---|---|
| 장작 도끼 | 돌쇠 처소 | 뒷문 마당 장독 | 도끼 커서로 장독 클릭 후 기본 커서 복귀 |
| 놋쇠 고리열쇠 | 사랑방 붓통에서 찾아 습득 | 호패 주머니 서랍, 혼서 문갑 | 열쇠 커서로 잠금쇠 클릭 |
| 매화무늬 장열쇠 | 조건을 충족해 무덕을 심문 | 춘월 방 검은 문갑 | 열쇠 커서로 문갑 클릭 |
| 작은 쇠열쇠 | 검은 문갑 거짓 바닥 | 춘월 방 의복장 | 열쇠 커서로 의복장 클릭 |

### 춘월 방의 고난도 흐름

```text
잠긴 검은 문갑 확인
→ 무덕의 번진 일기 확보·감식
→ 무덕에게 일기 제시
→ 문갑·열쇠·춘월 방 추궁
→ 매화무늬 장열쇠 획득
→ 검은 문갑 개방
→ 거짓 바닥 조사
→ 작은 쇠열쇠 획득
→ 잠긴 의복장 개방
→ 고름이 뜯긴 저고리 발견
```

## 10. 증거 → 상호작용 → 대조 → 사실 → 진술

| 증거 | 상호작용 | 대조 대상 | 밝혀지는 사실 | 연결되는 진술 |
|---|---|---|---|---|
| 찢어진 약속 편지 | 조각을 맞춰 복원 | 돌쇠 말투, 도망 보따리, 일기 | 창고 약속은 있으나 말투가 돌쇠답지 않음 | 돌쇠에게 작성 여부, 춘월에게 인지 시점 질문 |
| 호패 조각 | 훼손과 끈 구멍 확인 | 빈 호패 주머니, 끊어진 호패끈 | 자연 유실이 아니라 꺼내 훼손했을 가능성 | 유문석에게 분실 시점, 춘월에게 출입 이유 질문 |
| 돌쇠의 그림 | 천을 젖히고 그림 펼치기 | 도망 보따리 | 춘월이 돌쇠에게 오래 마음을 품었음 | 그림을 숨긴 이유 질문 |
| 무덕의 번진 일기 | 각 밤 기록을 직접 열람 | 하인 장부, 편지 | 점순의 외출과 정보 전달 흐름 | 무덕에게 누구에게 말했는지 질문 |
| 진흙 묻은 짚신 | 밑창 확인 | 작은 발자국 | 크기와 무늬가 달라 무덕의 신발이 아님 | 무덕의 밤 이동 의혹을 분리 |
| 빈 호패 주머니 | 잠긴 서랍을 열고 안쪽 확인 | 호패 조각, 호패끈 | 호패가 이 주머니에 있었고 끈이 끊긴 채 빠짐 | 유문석에게 마지막 확인 시점 질문 |
| 하인 장부 | 문서 더미에서 기록 확인 | 일기, 혼서 조각 | 춘월이 사랑방에 들어갈 기회가 있었음 | 춘월에게 사랑방에서 한 행동 질문 |
| 혼서 조각 | 잠긴 문갑을 열고 조각 맞추기 | 장부, 돌쇠의 그림 | 춘월이 원치 않는 혼인을 앞둠 | 혼인 압박과 방문 이유 질문 |
| 피 묻은 붕대 | 펼쳐 감긴 방향 확인 | 돌쇠의 팔 상처 | 돌쇠의 한 줄 작업 상처와 맞음 | 다친 경위와 시점 질문 |
| 도망 보따리 | 매듭을 풀어 내용 확인 | 편지, 일기 | 점순과 돌쇠가 함께 떠날 준비를 함 | 돌쇠에게 관계와 약속 추궁 |
| 작은 발자국 | 크기와 윤곽 채취 | 진흙 묻은 짚신 | 무덕의 짚신과 맞지 않음 | 발자국만으로 주인 확정 금지 |
| 끊어진 호패끈 | 호패 구멍에 대조 | 호패 조각, 주머니 | 굵기와 마찰 홈이 맞음 | 유문석에게 자연 유실 여부 질문 |
| 찢어진 옷고름 | 도끼로 장독을 깨고 습득 | 목 자국, 뜯긴 저고리 | 폭·직조·단면이 수법과 저고리에 연결됨 | 춘월에게 범행 당일 복장 질문 |
| 고름이 뜯긴 저고리 | 잠긴 의복장을 열어 확인 | 찢어진 옷고름 | 뜯긴 자리와 단면이 맞음 | 옷고름이 사라진 이유 질문 |
| 돌쇠의 팔 상처 | 소매를 올려 확인 | 붕대, 손톱 밑 흔적 | 붕대와 맞지만 여러 갈래 긁힘과 다름 | 거짓말과 살해 접촉을 분리 |
| 긁힌 팔 흔적 | 춘월의 소매 아래 확인 | 점순의 손톱 밑 흔적 | 간격과 방향이 마지막 저항 흔적과 닮음 | 점순을 만나지 않았다는 진술 반박 |

## 11. 핵심 증거 사슬

- 조작된 호패: `호패 조각 ↔ 빈 호패 주머니 ↔ 끊어진 호패끈 ↔ 하인 장부`
- 가짜 편지: `약속 편지의 말투 ↔ 돌쇠의 말투 ↔ 도망 보따리 ↔ 무덕의 일기`
- 살해 도구: `장작 도끼 → 장독 → 찢어진 옷고름 ↔ 목 압박 흔적 ↔ 뜯긴 저고리`
- 마지막 저항: `손톱 밑 흔적 ↔ 돌쇠의 한 줄 상처(불일치) ↔ 춘월의 긁힘(일치)`
- 동기: `돌쇠의 그림 ↔ 도망 보따리 ↔ 혼서 조각`

## 12. 심문 진행

- 보따리에서 증거를 선택한 뒤 질문하면 별도의 심문상·증거패·관인 미니게임 없이 곧바로 질문과 증거가 전달된다.
- 춘월: 그림에는 사적인 감정이라 방어하고, 혼서에는 혼인 압박을 인정한다. 일기와 보따리에는 무덕에게 이야기를 들었다고 부분 인정한다. 옷고름·저고리·팔 상처가 합쳐지면 진술이 무너진다.
- 돌쇠: 처음에는 관계와 밤 만남을 숨긴다. 일기와 보따리 뒤 도망 계획을 인정하며 편지의 정중한 말투를 부정한다. 붕대와 한 줄 상처로 살해 접촉과 분리된다.
- 유문석: 꾸짖은 일과 호패 분실을 축소한다. 호패·주머니·끈 뒤 자신의 물건임은 인정하지만 현장에 둔 적은 없다고 말한다.
- 무덕: 처음에는 밤 기척과 정보 전달을 숨긴다. 일기를 제시하면 인정한다. 춘월 방의 잠긴 문갑을 먼저 확인하고 일기를 제시한 뒤 열쇠를 추궁하면 `매화무늬 장열쇠`를 건넨다.

## 13. 범인 지목 조건

다음 다섯 축이 모두 연결될 때 지목 논리가 완성된다.

1. 기회: 하인 장부의 춘월 사랑방 출입
2. 유인: 돌쇠 말투와 다른 약속 편지
3. 수법: 찢어진 옷고름과 목 압박 흔적
4. 소유: 옷고름과 뜯긴 저고리의 단면 일치
5. 접촉: 손톱 밑 흔적과 춘월의 팔 긁힘

호패·그림·혼서만으로는 범인을 확정하지 않는다. 각각 누명, 감정, 동기를 설명하는 보조 증거다.

## 14. 공간 수색과 상태 규칙

- 전체 현장과 확대 현장은 같은 공간·사물 구성을 유지한다.
- 확대 수색은 작은 팝업이 아니라 해당 공간을 다시 구성한 전체 화면이다.
- 상호작용 대상에 커서를 올리면 커서 형태가 달라진다.
- 현장, 확대 화면, 보따리의 증거는 같은 형태·색·재질을 사용한다.
- 증거를 획득하면 현장에서 영구히 사라진다. `X`는 화면만 닫고 상태를 되돌리지 않는다.
- 가구와 천은 증거 수집 뒤에도 빈 상태로 열고 닫거나 젖히고 감출 수 있다.
- 닫는 동작에는 자막을 띄우지 않는다.
- 정답을 직접 알려 주는 지시문은 쓰지 않는다.
- 관찰 문구는 어두운 반투명 바탕과 얇은 금색 테두리로 통일하고 하나만 표시한다.
- 수집한 증거·도구·열쇠, 읽은 기록, 전령, 잠금 해제, 깨진 장독은 재진입 후에도 유지한다.

## 15. 증거 습득 UI 규칙

- 습득 시 기존 조선 테마의 증거 팝업을 사용한다.
- 팝업에는 현장과 동일한 이미지와 증거 이름을 크게 보여 준다.
- `증거를 보따리에 넣었습니다` 같은 별도 자막은 띄우지 않는다.
- 소매 확인으로 얻는 팔 흔적을 포함해 모든 증거 수집 경로에서 별도 습득 자막을 사용하지 않는다.
- 습득 팝업과 의문 메시지를 동시에 띄우지 않는다.
- 감식 화면의 불필요한 정사각형 판, 흰색 밑줄, 액자 테두리는 제거한다.

## 16. 사용하지 않는 옛 설정

- 인벤토리 물건 형태의 `압수수색패`, `호적조회령`
- 전령 절차에 등장하는 아전
- 무덕 방에서 발견되는 비단끈
- 나뭇가지에 걸린 찢어진 옷고름
- 독립 이동 장소인 창고 문간
- 옛 열쇠 이름 `검은 문갑 열쇠`, `사랑방 쇠열쇠`
- 폐기 증거 `헐거워진 노리개`, `매화 무늬 편지지`

현재 열쇠 이름은 `매화무늬 장열쇠`, `놋쇠 고리열쇠`, `작은 쇠열쇠`다.

## 17. 구현 검수 체크리스트

- [ ] 춘월 방은 편지와 일기를 나란히 확인하고 전령을 찍으면 열린다.
- [ ] 유문석 사랑방과 뒷문 마당에도 각각 올바른 전령이 적용된다.
- [ ] 무덕 하인방과 돌쇠 처소에는 전령이 없다.
- [ ] 모든 도구·열쇠는 획득 전 보따리에 보이지 않는다.
- [ ] 열쇠와 도끼는 커서가 바뀌고 올바른 대상에만 작동한다.
- [ ] 의복장, 호패 서랍, 혼서 문갑은 해당 열쇠 없이는 열리지 않는다.
- [ ] 장독 힌트는 `맨손으로는 잘 깨지지 않는다.`까지만 제공한다.
- [ ] 수집한 증거는 화면을 닫고 재진입해도 되살아나지 않는다.
- [ ] 닫기·재개폐·습득 뒤에 불필요한 자막이 뜨지 않는다.
- [ ] 현장·확대·보따리의 증거 이미지가 일치한다.
- [ ] 일기의 밤 기록은 읽을 수 있을 만큼 유지된다.
- [ ] 최종 지목은 동기뿐 아니라 수법·소유·접촉 증거까지 요구한다.

## 18. 결말과 해몽

- 플레이어는 춘월의 감정을 이해할 수는 있어도 범행을 정당화하지 않는다.
- 점순과 돌쇠의 관계는 비극의 원인이 아니라 억압에서 벗어나려던 선택으로 남긴다.
- 한 사건을 해결해도 다른 꿈이 남아 있다면 완전히 깨어나지 못한다.
- 세 꿈을 모두 해결했을 때 최종 각성과 해몽으로 이어진다.
