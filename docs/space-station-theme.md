# 우주정거장 테마: 오르빗-13 임상 은폐 살인 사건

## 1. 테마 한 줄 요약

우주정거장 `오르빗-13`에서 수석 엔지니어 데이비드가 외부 작업 중 우주로 튕겨 나가 사라진 사건임.  
겉으로는 장비 고장과 정전이 겹친 사고처럼 보이지만, 실제로는 불법 임상시험을 폭로하려는 데이비드를 주치의 메르스가 제거한 계획 살인이었음.

## 2. 플레이어 역할

- 역할: `비상 조사관`
- 호칭 방향: 대원들이 플레이어를 `조사관님` 또는 `비상 조사관`으로 부름
- 플레이 목표: 시신을 회수하지 못한 상황에서 불완전한 기록, 장비 흔적, 마지막 생체 신호와 대원 증언을 조합해 계획된 사고의 전 과정을 복원해야 함

## 3. 핵심 정서

- `의료 권한의 악용`, `불법 임상시험`, `진실 은폐`가 중심임
- 메르스는 환자의 신뢰를 이용해 데이비드를 실험 대상으로 삼고, 자신의 연구 성과와 보상을 지키려고 살인을 선택한 명백한 악역임
- 아인슈페너는 강한 페이크 진범으로 사용함
- 해리와 알라딘딘은 각자 수상한 이유가 있지만 후반에는 진실을 밝히는 조력자가 됨

## 4. 사건 구조

### 표면 사건

- 피해자 데이비드가 외부 통신 장치 점검을 위해 정거장 밖으로 나감
- 작업 중 산소 발생기실의 과부하로 정거장 일부 구역에 순간적인 전력 차단이 발생함
- 전력 이상으로 외벽 통신 장치의 고정 장치가 풀리고, 이탈한 외벽 패널이 데이비드의 안전 로프를 강타함
- 안전 로프 연결 고리가 파손되고 데이비드는 충격으로 정거장 뒤편 음영 구역인 `Shadow Zone`으로 튕겨 나감
- 데이비드는 안전 로프 없이 정거장으로 복귀하기 위해 우주복의 비상 추진 장치를 작동하려 함
- 데이비드는 마지막 무전으로 “안전 로프가 끊어졌다. 비상 추진 레버가 움직이지 않아. 얼어붙었어!”라고 외침
- 시신은 회수되지 않음

### 진짜 사건

- 메르스는 지구의 제약 연구기관과 몰래 거래하고, 정거장 대원에게 승인되지 않은 근육 재생 약물을 투여해 임상 데이터를 모으고 있었음
- 성공 데이터를 보내면 거액의 연구 보상과 우선 귀환권을 받기로 했으며, 데이비드에게는 일반 방사선 치료제라고 속여 약물을 반복 투여함
- 약물 부작용으로 데이비드의 근력이 급격히 약해졌고, 데이비드는 의료 기록에서 미승인 약물 코드를 발견함
- 데이비드는 지구 관제소에 메르스의 불법 임상시험을 폭로하려 했음
- 메르스는 연구 성과와 귀환 특혜를 잃고 처벌받는 것을 막기 위해 기록을 삭제하고 데이비드를 사고사로 위장해 살해함
- 데이비드의 마지막 무전은 실제 구조 요청이었으며, 메르스는 개인 의료 채널로 들어온 요청을 수신한 뒤 고의로 차단함

## 5. 핵심 반전 질문

- 초반 질문: `왜 외벽 부품이 이탈해 안전 로프를 강타했는가?`
- 중반 질문: `왜 전력 차단과 외벽 부품 이탈이 정확히 외부 작업 시간에 겹쳤는가?`
- 후반 질문: `왜 데이비드의 마지막 의료 채널 호출만 수동으로 차단됐는가?`
- 최종 질문: `메르스는 무엇을 숨기기 위해 환자이자 동료를 살해했는가?`

## 6. 범행 방법

### 1단계: 불법 투약 기록 삭제

- 메르스는 해리의 계정을 도용해 데이비드의 미승인 약물 투여 기록과 부작용 보고서를 서버에서 삭제함
- 겉으로는 해리가 정거장 데이터를 날린 실수처럼 보임
- 실제 목적은 불법 임상시험과 데이비드의 폭로 계획을 숨기고 자신의 연구 보상과 우선 귀환권을 지키기 위함

### 2단계: 우주복 레버에 투명한 덫 설치

- 메르스는 의료실의 `수술용 특수 밀봉 젤`을 사용함
- 이 젤은 정거장 내부에서는 투명한 액체라 육안으로 보이지 않음
- 메르스는 데이비드의 비상 추진 장치 안전 레버 홈에 젤을 미세하게 채움
- 알라딘딘이 내부에서 우주복을 점검했을 때는 젤이 액체 상태라 이상을 발견하지 못함

### 3단계: 산소 발생기 시한 고장

- 메르스는 소독용 메스로 산소 발생기 압력 밸브의 미세 센서를 손상시킴
- 장치는 가동 후 약 5시간 뒤 압력 과부하를 일으키도록 조작됨
- 과부하 시간은 데이비드의 외부 작업 시간과 맞춰져 있음
- 산소 발생기에서 뿜어진 고압 수증기가 환기 배관을 타고 퍼지고, 메인 전력 차단기가 내려감

### 4단계: 외벽 부품 이탈과 안전 로프 파손

- 전력 차단 순간 외부 통신 장치의 전자식 고정 장치가 해제됨
- 정거장의 진동과 기존 관성으로 외벽 패널이 구조물에서 이탈함
- 이탈한 패널이 데이비드의 안전 로프를 강타해 연결 고리를 파손함
- 충격을 받은 데이비드는 안전 로프를 잃고 정거장에서 멀어지기 시작함

### 5단계: Shadow Zone의 얼어붙은 레버

- 데이비드가 태양 빛이 닿지 않는 정거장 뒤편으로 튕겨 나감
- 영하 150도 이하의 그늘 구역에서 레버 홈에 있던 젤이 강철처럼 얼어붙음
- 비상 추진 장치는 안전 로프가 끊겼을 때 자세와 이동 방향을 조절해 정거장으로 복귀하기 위한 최후의 수단임
- 레버는 추진 장치의 안전 잠금을 해제하고 추진 가스 밸브를 여는 활성화 손잡이임
- 얼어붙은 레버가 움직이지 않아 데이비드는 추진 가스를 분사하거나 정거장 방향으로 복귀할 수 없게 됨
- 데이비드는 마지막 순간 메르스의 개인 의료 채널로 구조를 요청함
- 메르스는 호출을 수신한 뒤 채널을 수동으로 차단해 구조 가능성을 없애고 사고 위장을 완성함

## 7. 등장인물

### 데이비드

- 피해자
- 수석 엔지니어이자 오르빗-13의 핵심 시스템 관리자
- 메르스를 신뢰해 일반 치료제로 알고 약물을 투여받았음
- 약물 부작용과 미승인 약물 코드를 발견한 뒤 지구 관제소에 폭로하려 함
- 죽음에 동의하거나 메르스에게 살해를 부탁한 적이 없음

### 메르스

- 주치의 / 최종 진실의 중심
- 항상 마스크를 쓰고 수술용 메스를 지님
- 겉으로는 연결선 절단에 쓸 도구를 가진 의심 인물처럼 보임
- 실제로는 메스로 산소 발생기 센서를 조작하고, 수술용 밀봉 젤로 추진 장치 레버를 봉인함
- 불법 투약 기록과 부작용 보고서를 지우기 위해 해리 계정을 도용함
- 연구 보상과 우선 귀환권을 잃고 처벌받는 것을 막기 위해 데이비드를 계획적으로 살해함
- 결정적 증거를 들이밀면 치료를 위한 위험이었다고 합리화하다가, 끝내 자신의 성과를 빼앗길 수 없었다는 본심을 드러냄

### 아인슈페너

- 과학자 / 강한 페이크 진범
- 커피를 들고 다니며 화학약품 냄새가 남
- 승인받지 않은 개인 실험을 숨기고 있음
- 데이비드와 갈등이 있었고, 커피 텀블러와 실험실에 숨겨진 약물 앰풀 때문에 초반에는 거의 범인처럼 보임
- 하지만 데이비드의 죽음 자체는 메르스의 계획임
- 본인은 불법 실험을 숨기려고 거짓말하지만, 최종 살인자는 아님

### 해리

- 데이터/통신 담당
- 경제학자이자 컴퓨터공학자
- 정거장 로그를 날려 먹었다고 자책함
- 실제로는 메르스가 해리 계정을 도용해 데이비드의 불법 투약 기록을 지운 것
- 후반에 삭제된 로그 조각을 복구해 메르스의 의료실 접근, 산소 발생기 점검 기록 이상을 찾아냄

### 알라딘딘

- 엔지니어
- 데이비드와 업무 갈등이 있었음
- 우주복 점검 담당이라 강하게 의심받음
- 내부 점검 당시 레버 젤은 투명 액체 상태라 발견할 수 없었음
- 외벽 장치와 우주복 구조를 잘 알아 의심받지만, 결정적 수법은 의료용 젤과 의료 도구였음

## 8. 조사 장소

1. `에어록`
   - 외부 작업 준비 기능까지 포함한 첫 현장
   - 추진 레버 젤, 마지막 무전, 엔지니어 공구 점검 흔적 확인

2. `의료실`
   - 수술용 밀봉 젤을 사용한 흔적과 삭제된 불법 투약 기록 확인

3. `산소 발생기실`
   - 압력 센서 손상과 외부 작업 시간에 맞춘 지연 타이머 확인

4. `데이터실`
   - 해리 계정 도용 기록과 메르스의 연구 보상 계약 복구

5. `과학 실험실`
   - 아인슈페너의 커피 텀블러와 개인 실험 흔적 확인
   - 아인슈페너를 의심하게 하는 미끼와 메르스가 숨긴 약물 앰풀 확인

## 9. 증거 목록

### 에어록

- `추진 레버 결빙 기록`: 데이비드의 우주복 추진 레버가 외부 작업 중 결빙되어 응답을 멈춘 원격 진단 기록
- `마지막 무전 로그`: 데이비드가 메르스에게 구조를 요청했지만 메르스가 채널을 차단했다는 결정타
- `엔지니어 공구 클램프`: 공구에 젤 흔적이 없어 알라딘딘의 점검 조작 의혹을 약화하는 무혐의 증거

### 의료실

- `소독천과 장갑`: 레버 젤과 메르스가 사용하는 의료용 소독제를 연결하는 흔적
- `삭제된 의료 기록`: 미승인 약물 투여와 심각한 부작용을 숨겼다는 불법 임상시험 증거

### 산소 발생기실

- `손상된 압력 센서`: 메스와 같은 얇은 날붙이로 정전 장치를 고의 손상했다는 수법 증거
- `조작된 지연 타이머`: 정전이 외부 작업 시간에 맞춰 예약됐고 의료실 단말에서 설정됐다는 알리바이 파괴 증거

### 데이터실

- `접속 키카드 칩`: 해리 계정으로 실행된 기록 삭제가 실제로는 의료실 단말에서 이루어졌다는 계정 도용 증거
- `암호화된 연구 보상 계약`: 메르스가 임상 자료 대가로 거액의 보상과 우선 귀환권을 약속받았다는 결정적 동기 증거

### 과학 실험실

- `커피 텀블러`: 아인슈페너를 의심하게 하지만 살인 수법과는 연결되지 않는 미끼 증거
- `미승인 약물 앰풀`: 메르스가 불법 약물을 실험실에 숨겨 아인슈페너에게 책임을 씌우려 했다는 위장 증거

## 10. 심문 반응 및 전용 정보

- 물적 증거는 사건에 어떤 조작이 있었는지를 밝히고, 심문은 그 행동을 누가 했는지 연결하는 역할을 함
- 각 용의자는 기록이나 현장 증거로는 얻을 수 없는 목격, 기억 또는 사적인 행동을 하나씩 알고 있음
- 관련 증거나 다른 용의자의 증언으로 모순을 지적해야 핵심 증언이 열림

### 메르스

- 최초 진술: 정전 당시 의료실에 있었으며 데이비드에게 시행한 처치는 모두 정상 절차였다고 주장함
- `손상된 압력 센서`와 `조작된 지연 타이머` 제시: 정전 순간의 알리바이만 반복하지만 장치가 미리 설정됐다는 사실은 설명하지 못함
- `삭제된 의료 기록`과 `미승인 약물 앰풀` 제시: 약물 투여를 치료 목적이었다고 합리화함
- `암호화된 연구 보상 계약` 제시: 연구 성과와 우선 귀환권에 대한 집착을 드러냄
- 심문 전용 결정타: 플레이어가 공개하지 않은 데이비드의 증상 발생 시각이나 투여량을 메르스가 무심코 언급해 범인만 알 수 있는 정보를 알고 있음이 드러남
- `추진 레버 결빙 기록`과 `마지막 무전 로그`까지 연결하면 구조 가능성을 고의로 차단한 사실을 더는 설명하지 못함

### 아인슈페너

- 최초 진술: 사건 전부터 과학 실험실에 있었으며 메르스를 보지 못했다고 주장함
- `커피 텀블러` 제시: 승인받지 않은 개인 실험을 하느라 자신의 위치를 숨겼다고 인정함
- `미승인 약물 앰풀` 제시: 앰풀은 자신의 시약이 아니며 의료용 물품에 가깝다고 설명함
- 심문 전용 정보: 21시 47분경 메르스가 앰풀이 든 냉각 보관함을 들고 의료실 방향으로 이동하는 모습을 목격했다고 밝힘
- 살인에 사용된 의료 물품과 자신의 개인 실험이 별개였음이 확인되며 용의선상에서 벗어남

### 해리

- 최초 진술: 의료 기록 삭제도 자신의 데이터 관리 실수였을 가능성이 있다고 자책함
- `접속 키카드 칩` 제시: 자신의 계정이 의료실 보조 단말에서 사용된 시각에는 그곳에 없었다고 확인함
- 심문 전용 정보: 21시 43분경 메르스가 의료 단말기 오류를 확인한다며 키카드를 빌려 갔고, 돌려받았을 때 칩 가장자리가 손상돼 있었다고 밝힘
- 계정 도용 경로를 밝힌 뒤 삭제 기록 복구를 돕는 조력자로 전환함

### 알라딘딘

- 최초 진술: 외부 작업 전 데이비드의 우주복을 정상적으로 점검했다고 강하게 주장함
- `엔지니어 공구 클램프`와 `추진 레버 결빙 기록` 제시: 출발 전 점검은 정상이었고, 원격 진단에는 외부 작업 중 레버가 급격히 결빙된 것으로 기록됐다고 설명함
- 심문 전용 정보: 22시 11분경 에어록 근처에서 메르스가 누군가와 무전하며 “이제 시간만 맞으면 된다”고 말하는 것을 들었다고 밝힘
- 메르스가 지연 타이머 작동 전에 에어록에 있었다는 시간선 연결 고리를 제공함

## 11. 핵심 게임 시스템

### 산소 잔량 제한

- 장소를 이동하거나 정거장 설비를 사용할 때 조사관의 휴대 산소가 감소함
- 증거 설명을 읽거나 심문하는 동안에는 산소가 감소하지 않음
- 휴대 산소가 처음으로 25% 이하가 되면 경고음과 붉은 화면 효과가 나타나고 `긴급 산소 복구` 이벤트가 시작됨
- 이벤트가 시작되면 일반 장소 이동과 추가 조사가 잠시 제한되고 산소 발생기실로 이동해야 함
- 산소 부족은 즉시 게임 오버로 이어지지 않으며, 퍼즐 실패로 산소가 10%에 도달하면 추가 감소를 멈추고 복구 안내를 강화함
- 조사관의 휴대 산소와 데이비드 우주복의 사건 당시 산소 기록은 서로 다른 수치로 명확히 구분함

#### 긴급 산소 복구 퍼즐

- 퍼즐은 게임 중 한 번만 발생하며 `잘못된 센서 값 확인 → 자동제어 차단 → 비상 우회 → 수동 압력 조절 → 비인가 회로 조사 → 산소 발생기 재가동` 순서로 진행됨
- 단순한 조작 순서 암기가 아니라, 서로 모순되는 계기 값을 비교하고 사건 데이터를 보존하는 판단이 핵심임

##### 초기 제어반 상태

```text
O₂ EMERGENCY CONTROL

[A. 주 공급 계통]
밸브 상태       CLOSED
실제 공급 압력  18%

[B. 압력 감시 계통]
센서 P-02       100%
상태            NORMAL

[C. 비상 우회 계통]
BYPASS          CLOSED
출력 압력       0%
```

- 화면의 `100%`는 실제 압력값이 아니라 P-02 센서가 정상 상태라고 잘못 보고하는 정규화된 표시값임
- 시스템은 P-02의 값을 믿고 산소 공급이 충분하다고 판단하기 때문에 주 공급 밸브를 열지 않음
- 옆의 기계식 압력 게이지는 실제 공급 압력 18%를 표시해 디지털 센서와 모순됨

##### 1단계: 손상된 센서 판별

- `자동 복구`를 누르면 시스템은 P-02의 100% 표시를 근거로 공급이 충분하다고 판단하고 복구를 중단함
- 플레이어에게 `센서 재보정`, `센서 연결 차단`, `주 공급 밸브 강제 개방` 선택지를 제공함
- 재보정은 센서 응답 오류로 실패하고, 밸브 강제 개방은 안전 잠금 때문에 차단됨
- 기계식 게이지와 디지털 표시의 모순을 근거로 `센서 연결 차단`을 선택해야 함
- 이 과정에서 P-02가 기존 증거인 `손상된 압력 센서`와 동일한 장치임이 확인됨

##### 2단계: 비상 우회 계통 활성화

- P-02를 차단하면 자동제어가 해제되고 `EMERGENCY BYPASS` 레버가 활성화됨
- 우회 레버를 당기면 산소가 수동 계통으로 흐르며 공급 압력이 약 38%까지 상승함
- 파이프 조명과 게이지 변화로 산소 흐름이 복구되고 있음을 시각적으로 보여줌

##### 3단계: 수동 압력 조절

- 플레이어는 밸브의 `-`와 `+` 조작을 이용해 공급 압력을 안전 범위인 65~80%에 맞춰야 함
- 65% 미만이면 공급 부족, 80%를 초과하면 과압 위험 경고가 나타남
- 안전 범위에 들어오면 `MANUAL PRESSURE STABLE` 상태가 되지만, 비인가 보조 신호 때문에 시스템 재가동은 여전히 실패함
- 잘못된 조작 한 번당 휴대 산소가 2% 감소하지만 10% 아래로는 떨어지지 않음

##### 4단계: 비인가 보조 회로 발견

- 압력이 정상화된 뒤 제어반에서 정상 배선과 다른 노란색 `AUX-04` 회로가 점멸함
- AUX-04는 산소 공급 제어와 외벽 통신 장치 고정 전력 계통에 동시에 연결돼 있음
- 회로를 따라가면 기존 증거인 `조작된 지연 타이머`가 숨겨져 있음이 드러남
- 이 시점에서 산소 고장이 단순한 기계 결함이 아니라 의도적으로 준비됐을 가능성이 처음 명확해짐

##### 5단계: 예약 데이터 보존

- 타이머에서 `전원 차단`, `장치 분리`, `예약 데이터 확인`을 선택할 수 있음
- 전원 차단이나 즉시 분리를 먼저 선택하면 휘발성 메모리가 사라질 수 있다는 경고를 표시함
- 정답은 `예약 데이터 확인 → 장치 분리`이며, 플레이어가 정비공뿐 아니라 수사관처럼 행동하도록 유도함
- 잘못된 선택을 해도 데이터가 실제로 소실되지는 않고 경고 후 다시 선택할 수 있게 함

##### 6단계: 숨겨진 시간 기록 획득

```text
AUXILIARY TIMER MEMORY

예약 등록       OST 22:05:17
실행 예정       OST 22:18:00
실행 완료       OST 22:18:00

COMMAND 01      O₂ SUPPLY LIMIT
COMMAND 02      EXTERIOR FIXTURE POWER CUT
SOURCE TERMINAL MEDICAL AUX-02
```

- `22:05 비인가 제어 명령 예약`과 `22:18 예약 명령 실행`이 사건 시간선에 자동 등록됨
- 플레이어는 사고 시각인 22:18에 누군가 현장에서 조작한 것이 아니라, 22:05에 예약된 명령이 자동 실행됐음을 알게 됨
- 명령이 의료실 보조 단말에서 등록됐다는 사실까지만 공개하고, 메르스 개인의 행동은 심문 증언으로 확인하게 함

##### 7단계: 산소 발생기 재가동

- 예약 데이터를 보존한 뒤 AUX-04 타이머를 분리하고 산소 발생기를 재가동함
- 수동 압력은 72%로 안정되고 중앙 산소 공급이 정상 상태로 전환됨
- 조사관의 휴대 산소가 현재 수치에서 70%까지 회복되고 장소 이동 제한이 해제됨
- 이후 장소 이동 시 산소 소모량을 줄여 같은 퍼즐이 반복되지 않도록 함
- 복구 완료 후 `정비 기록과 일치하지 않는 비인가 제어 흔적이 발견되었습니다`라는 메시지와 함께 새로운 심문 질문이 열림

#### 퍼즐 이후 열리는 심문

- 알라딘딘에게 `22시 05분부터 22시 18분 사이 에어록이나 산소 발생기실 근처에서 누구를 보았는가?`를 질문할 수 있음
- 메르스에게 `22시 18분에 의료실에 있었다는 사실이 22시 05분에 설정된 타이머와 무슨 관계가 있는가?`를 추궁할 수 있음
- 퍼즐 기록은 의료실과 범행을 연결하지만 범인을 바로 확정하지 않으며, 알라딘딘의 목격과 해리의 키카드 대여 증언이 함께 있어야 메르스에게 연결됨

### 정거장 시간 재구성

- 무전, 의료 기록, 지연 타이머, 출입 기록과 심문 증언을 정거장 표준시 순서로 배치함
- 물적 증거만으로 채울 수 없는 시간대는 해리, 아인슈페너와 알라딘딘의 심문 전용 증언으로 완성함
- 메르스가 정전 순간 의료실에 있었다는 주장은 사실이지만, 지연 타이머를 미리 설정했다는 점이 밝혀지면서 알리바이로서 의미를 잃음
- 완성된 시간선은 `불법 계약 → 약물 반출 및 투여 → 타이머 설정 → 센서 조작 → 외부 작업 → 전력 차단과 로프 파손 → 추진 레버 작동 실패 → 마지막 무전 → 기록 삭제` 순서가 됨

## 15. 구현 메모

- 11개의 증거는 에어록, 의료실, 산소 발생기실, 데이터실, 과학 실험실의 5개 장소에 나누어 배치하고, 화면 버튼과 겹치지 않으면서 현장 안에서 자연스럽게 발견되도록 구성함
- 정거장 내부는 인공중력이 유지되는 설정이므로 무중력 부유 연출을 사용하지 않으며, 증거는 작업대, 제어함, 폐기함, 장비 홈과 바닥 등 장소의 용도에 맞게 배치함
- 물적 증거만으로 범인을 확정하지 않고, 보안 조사실에서 각 용의자의 목격과 비공개 정보를 확보해야 전체 시간선과 범인의 행동이 완성되도록 구성함
- 메르스는 초반에는 침착한 주치의로 신뢰를 얻지만, 최종 지목 과정에서는 불법 임상시험의 성과와 우선 귀환권을 지키기 위해 환자이자 동료인 데이비드를 계획적으로 희생한 명백한 악역으로 드러나야 함
